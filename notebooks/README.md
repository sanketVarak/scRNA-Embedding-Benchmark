# Notebooks

## `scrna_embedding_benchmark.ipynb`

The structured and documented notebook for reproducing the scRNA-seq embedding benchmark. It uses the helper module in `src/scbench.py` and generates the analysis figures and result tables when run in the documented Kaggle environment.

The separately supplied original Kaggle notebook was used to recover its saved PNG outputs. It is not included in this repository as an unchanged notebook upload. Those visuals are stored in `results/figures/` and linked from the structured notebook and root README.
